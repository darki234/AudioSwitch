# AudioSwitch

Маленькая фоновая утилита для Windows на Rust: по клавише **Num 1** переключает вывод звука между устройствами (например, динамики ноутбука и наушники). При переключении в правом нижнем углу появляется плавающая карточка с названием устройства.

## Сборка и запуск

Нужен Rust (stable).

```
cargo build --release
```

Готовый файл: `target/release/AudioSwitch.exe`. Запустите его, он работает в фоне (один экземпляр). Чтобы он стартовал вместе с Windows, положите ярлык в `shell:startup`.

## Команды

```
AudioSwitch.exe                       работать в фоне, Num 1 переключает устройство
AudioSwitch.exe once                  переключить один раз и выйти
AudioSwitch.exe list                  записать список активных устройств в list.txt
AudioSwitch.exe demo [подпись название 0|1]   показать карточку без переключения звука
```

## devices.txt

Файл рядом с `AudioSwitch.exe`. Какие устройства переключать: часть названия, по одному на строку. Строка с `!` в начале исключает устройство, `#` начинает комментарий, пустой файл означает «все». Пример:

```
!Steam Streaming
```

Карточка рисуется шрифтом Segoe UI из системной папки Fonts.
